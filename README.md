# Ratecore Store Demo — store releases

Built files only (no source). Each release `store-<version>` holds the front store build used by the
Ratecore Store Demo desktop app (`store-<version>.zip`) and `latest.json`, the manifest the app reads from
`https://github.com/WeAreMove/ratecore-store-demo-releases/releases/latest/download/latest.json` to offer
in-app updates. Published with `npm --prefix desktop run store:publish` from the demo line of
ratecore-frontstore-default-template (branch `demo/desktop-app`).
